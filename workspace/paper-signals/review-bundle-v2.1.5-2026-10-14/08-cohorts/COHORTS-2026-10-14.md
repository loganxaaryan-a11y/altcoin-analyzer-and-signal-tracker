## Quarantine statement

`cohort-retrospective-v2.csv` has **no read path into pilot statistics**:

- `collect_pilot_rows.py` reads exactly one input path, hardcoded as
  `PILOT_CSV = rows/comparison-rows-pilot-2026-10-14.csv`. It performs no
  globbing or directory discovery (no `glob`/`listdir` in the file — grepped
  2026-10-14), and `validate_candidate` refuses non-`pilot` row origins and
  the v1 paths.
- `metrics.py::read_rows(path)` takes an explicit CSV path argument; no file
  is hardcoded, and nothing discovers `cohort-*` or `retrospective` paths.
- Nothing on disk currently names the retrospective file, so the only way
  it could enter pilot statistics is an explicit future code change.

The retrospective file is a separate readout dataset (retrospective
accounting per the rules above), never an input to collection or to pilot
metrics. If future work needs it fed anywhere, that is a named decision —
the v2.1.0 consolidation workstream enforces this boundary. No pipeline code
was rewritten in this step (per the task: noted, not changed).
