# actionable-entry-v1 (sandbox)

Implements the `actionable-entry-v1` contract drafted in
`source-export-2026-10-13/ENTRY-SEMANTICS.md`. **Sandbox only** — no
production changes, no live trading, holdouts locked. Compiled with
`tsc --strict`; run `node dist/test/entry-v1.test.js` (24 tests),
`node dist/test/corrections-1-3.test.js` (12 tests), and
`node dist/test/watcher.test.js` (7 tests) — 43 tests, all green.

## Notes / caveats

- **Rejection policy (correction 1):** `enterContract` rejects by THROWING `ContractError` carrying a machine-readable `reasonCode` from `ENTRY_REJECTION_REASON` — never a soft return. Throw was chosen because the whole entry-v1 boundary already throws; a return-based rejection would let integrity violations look like business outcomes. Assert on reason codes in tests, never on message substrings.
- **decisionAt semantics (correction 3):** `decisionAt` is the actual instant the qualification/issuance logic ran. `sourceObservedAt` is the source bar's observation (e.g. the session close). Equity accepts an optional `decisionAt` (the scan's run time); crypto already takes it. An entry print predating `decisionAt` is rejected with `entry-before-decision`.
- The XNYS calendar in `entry-rules.ts` is a **sandbox test calendar** (2025–2027 weekends + listed holidays/early closes). Production must use the validated calendar (`isXnysSession`, equity measurement.ts:78-83). Dates outside 2025–2027 throw rather than guess.
- Eastern-time math is hand-rolled (US DST rules); verified against known instants in tests (e.g. 2026-10-09 16:00 EDT = 20:00Z; 2025-11-28 13:00 EST = 18:00Z).
- Per the spec, v1 equity entries are the next session's consolidated-tape open print; crypto entries are the first Binance Spot trade with venue time ≥ decisionAt inside the 15-minute window. Favorable-drift fills outside the band are voided (anti-selection-bias), not kept.
- Any change to decision-time definition, observation semantics, entry rule, venue, expiry, or drift caps requires a new contract version (`actionable-entry-v2`); v1 rows keep v1 terms forever.
